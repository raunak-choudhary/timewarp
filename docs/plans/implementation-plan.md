### Task 2.4 — Wire Everything Together
**File:** `backend/instrumentation.py` (update)
- After each node execution:
  1. `snapshot_engine.snapshot_node_execution(...)` → Checkpoint
  2. `drift_detector.score(node_name, output_text)` async → DriftEvent
  3. `anomaly_graph.add_node(checkpoint, drift_event.drift_score)` → updates DAG
  4. If `drift_event.is_anomaly`: run `anomaly_graph.get_anomaly_path()` → attach to WS msg
  5. `ws_manager.broadcast(checkpoint_to_ws_message(...))` → frontend updates

## Fallback Plans (if time runs out)

**If Phase 2 algorithms are not complete:**
Use hardcoded anomaly detection (threshold on output length) instead of Bellman-Ford.
Still mark nodes red. The rewind still works. The visual story still lands.

**If Three.js 3D is not working:**
Fall back to D3 force-directed 2D graph. Still shows nodes, edges, colors. Not as impressive
but the rewind mechanic still works.

**If Azure deploy fails:**
Demo from localhost. Judges accept this. Just say "live deploy encountered an issue, but
here is the working local version." Do not waste more than 10 minutes on Azure if it is
breaking.

**If Supabase has issues:**
Switch to SQLite in-memory store for the demo. All checkpoint operations work identically.
Use `aiosqlite` as drop-in replacement.
